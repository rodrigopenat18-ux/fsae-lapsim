# Data

| Pasta | O que tem |
|---|---|
| `Cars/` | carros em JSON. `default.json` é o carro de 2024. Crie outros pela aba "Carros" da interface ou copiando o arquivo. |
| `Tracks/` | pistas em CSV (`length_m,radius_m,slope,type`) |
| `Private/` | seus dados que **não vão para o Git**: logs de aquisição, GPX, exportações do OptimumLap etc. Crie a pasta se quiser usar. |

Os formatos aceitos de pista e o formato do JSON do carro estão descritos no
[README principal](../README.md#pistas).
